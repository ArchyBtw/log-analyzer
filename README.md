# Анализатор логов

> Выводит программы которые встречаются в логах
> Выводит краткую сводку про использование sudo

## Требования

> Linux с systemd;
> проверено на Python 3.14

## Как запустить

```
python analyzer.py
```

## Как работает

Программа читает журнал текущей загрузки (`journalctl -b`) и выводит:

- топ-5 программ по числу записей;
- сводку по `sudo`: число записей, число неверных паролей, список запущенных команд.

Программа только читает журнал и ничего не изменяет.
